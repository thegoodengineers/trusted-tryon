A try-on image is drawn by a model

  • It can get the colour wrong
  • It can hand back your own photo, unchanged
  • It is not drawn to scale, so it can't show fit
  • And nobody tells the shopper

How we use the Clothsy AI try-on API

  • POST /images once per visit; every garment reuses the photo id
  • POST /tryons with an idempotency key: a retry is never charged twice
  • GET /tryons/{id} polled, with progress shown step by step
  • Documented retry rules; every error code becomes a plain sentence
  • The API's AI label read from every result; GET /account for credits
